WHAT MUST NOT CHANGE IS THE SCIENCE

This program exists to answer three questions: is there an event in this data,
when did it happen and which template found it, and how confident are we that it

same way. It does not have to produce the same bits. It has to produce the same
conclusions.

So the arithmetic is yours. Single precision, a different FFT library, a
different reduction order, a different binning, another language — all of it is
open, if the science survives.

Two things that are not open, because they are the science rather than the
implementation. The search must stay blind: it may not use any knowledge of where
the event is or which template finds it, and it must still search the same
parameter space rather than a corner of it. And everything reported must still be
computed from `strain.npy` on every run — caching a result to disk and reading it
back is not a speed-up, it is a different program.

THE CHECKER IS A FLOOR, NOT A DEFINITION
