# NANOGrav 15yr: Bayesian Limits on GWs from Individual SMBHBs

**Source:** arxiv 2306.16222 (tex tree not fetched; see `references/` README convention)
**Bib key:** `NANOGrav:2023individual` → see [[../bibliography]]
**Type:** arxiv paper (provides the observational upper-limit benchmark for Fig. 8 / Table II)
**Ingested:** 2026-06-24

## Summary

Agazie et al. (NANOGrav, 2023) place Bayesian upper limits on continuous gravitational
waves (CWs) from individual supermassive black hole binaries (SMBHBs) in the 15-year,
67-pulsar NANOGrav dataset. No CW source is detected. The headline result is a
sky-averaged $95\%$ upper limit on an individual source's strain amplitude that is
frequency-dependent, reaching its deepest value $h_0 = 8\times10^{-15}$ near the
most sensitive frequency $f \approx 6$ nHz $\approx 0.19\,{\rm yr}^{-1}$. This is the
companion individual-source (CW) search to the NANOGrav 15yr GWB detection
(`NANOGrav:2023gor`) and anisotropy (`NANOGrav:2023tcn`) papers.

Published as ApJL 951 L50 (2023).

## Key results (individual-source / CW upper limits)

- **Deepest all-sky $95\%$ upper limit:** $h_0 = 8\times10^{-15}$, reached only near
  the most sensitive frequency $f \approx 6$ nHz $\approx 0.19\,{\rm yr}^{-1}$.
- **The limit is strongly frequency-dependent.** It rises steeply below $\sim$3 nHz
  toward the $1/T_{\rm obs}$ floor (lowest accessible frequencies), and degrades
  (weakens) to $\gtrsim 10^{-14}$ above $\sim$20 nHz. The $8\times10^{-15}$ value is
  therefore the single most constraining point on the curve, NOT a flat all-frequency
  bound.
- The limit is sky-averaged (all-sky); the directional limit varies with source
  position relative to the pulsar array.

    its $f \approx 6$ nHz location; caption notes the true limit is frequency-dependent
    and weaker elsewhere.

## Relevance to the project's argument

The brightest-source fraction $p_1$ controls the loudest pixel amplitude; converting
that pixel amplitude to a per-source strain $h_0 = \sqrt{h_s^2/(f\,T_{\rm obs})}$ lets
the project test whether the astrophysically expected loudest source is already in
tension with NANOGrav's individual-source (CW) sensitivity. The key takeaway is that
the predicted loudest source sits at or just below the deepest CW limit only for the
high-$\varepsilon$ model at the lowest frequencies, which is consistent with the
non-detection in this paper. Because the published limit is frequency-dependent (and
weaker away from $\sim$6 nHz), comparisons at other frequencies must use the
appropriate point on the curve, not the $8\times10^{-15}$ floor.

## Caveats / open questions

- The $8\times10^{-15}$ value is the deepest point of a frequency-dependent curve, not
  a flat bound. Any figure or claim that draws it as a single horizontal line must say
  so (Fig. 8 caption already does).
- The limit is sky-averaged; a directional comparison would need the per-position
  sensitivity, which is not used in the current paper.
